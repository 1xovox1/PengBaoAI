3. 点击“API 访问”或“设置”
4. 复制 API Key

## 📋 第二周：集成 Agent 编排服务

### ✅ 任务 3：修改直播前生成接口
修改 `server/routes/live.js` 的 `generate-pre` 接口，使用 `agentOrchestrator.orchestrateLivePre()`：

```javascript
// 在文件顶部添加
import { orchestrateLivePre } from '../services/agentOrchestrator.js'

// 修改 POST /api/live/runs/:id/generate-pre 接口
router.post('/live/runs/:id/generate-pre', async (req, res, next) => {
  try {
    const runs = await loadRuns()
    const idx = runs.findIndex((r) => r.id === req.params.id)
    if (idx === -1) return res.status(404).json({ error: 'run 不存在' })

    const run = runs[idx]
    
    // 使用 Agent 编排服务
    const result = await orchestrateLivePre({
      title: run.title,
      platform: run.platform,
      period: run.period,
      policyPrice: run.policyPrice,
      goods: run.goods,
      trafficExpect: run.trafficExpect,
      anchorState: run.anchorState,
      goal: run.goal,
    })

    // 更新 run
    run.preScript = result.finalOutput
    run.preScriptSteps = result.steps // 保存步骤信息（用于前端展示）
    run.preScriptScenario = result.scenarioOutput // 保存场景输出（用于查看）
    run.preScriptHistory = result.historyOutput // 保存历史输出（用于查看）
    run.updatedAt = nowIso()
    
    await saveRuns(runs)
    res.json({ run, steps: result.steps })
  } catch (e) {
    next(e)
  }
})
```

## 📋 第三周：数据清洗服务集成

### ✅ 任务 6：添加 Excel 上传接口
在 `server/routes/files.js` 中添加 Excel 解析接口：

```javascript
import { cleanAdsData, cleanTrafficData, cleanPerformanceData } from '../services/dataCleaner.js'
import multer from 'multer'

const upload = multer({ storage: multer.memoryStorage() })

// 新增：投放数据清洗接口
router.post('/files/clean-ads-data', upload.single('file'), async (req, res, next) => {
  try {
    if (!req.file) return res.status(400).json({ error: '请上传文件' })
    const { platform } = req.body
    if (!platform) return res.status(400).json({ error: '请指定平台' })

    const result = await cleanAdsData({
      platform,
      excelBuffer: req.file.buffer,
    })

    res.json(result)
  } catch (e) {
    next(e)
  }
})

// 新增：直播流量数据清洗接口
router.post('/files/clean-traffic-data', upload.single('file'), async (req, res, next) => {
  try {
    if (!req.file) return res.status(400).json({ error: '请上传文件' })
    
    const result = cleanTrafficData(req.file.buffer)
    res.json(result)
  } catch (e) {
    next(e)
  }
})

// 新增：直播数据表现清洗接口
router.post('/files/clean-performance-data', upload.single('file'), async (req, res, next) => {
  try {
    if (!req.file) return res.status(400).json({ error: '请上传文件' })
    
    const result = cleanPerformanceData(req.file.buffer)
    res.json(result)
  } catch (e) {
    next(e)
  }
})
```

### ✅ 任务 7：前端添加 Excel 上传功能
修改 `src/views/AdsLoopView.vue`，添加“上传 Excel 自动清洗”功能：

```vue
<el-form-item label="关键指标">
  <el-upload
    :auto-upload="false"
    :on-change="handleAdsFileChange"
    accept=".xlsx,.xls"
    :show-file-list="false"
  >
    <el-button>上传 Excel 自动清洗</el-button>
  </el-upload>
  <el-input
    v-model="form.kpisText"
    type="textarea"
    :rows="5"
    placeholder="粘贴关键指标或上传 Excel..."
  />
</el-form-item>

<script>
async handleAdsFileChange(file) {
  const formData = new FormData()
  formData.append('file', file.raw)
  formData.append('platform', this.form.platform)
  
  try {
    const res = await fetch('/api/files/clean-ads-data', {
      method: 'POST',
      body: formData,
    })
    const data = await res.json()
    this.form.kpisText = data.kpisText
    this.$message.success('数据清洗完成')
  } catch (e) {
    this.$message.error('数据清洗失败：' + e.message)
  }
}
</script>
```

## 📝 注意事项

1. **Agent Key 配置**：
   - 如果某个 Agent 还没创建，可以先不配置对应的环境变量
   - 系统会 fallback 到默认的 `DIFY_API_KEY`（如果配置了）

2. **Excel 格式**：
   - 数据清洗服务支持常见的 Excel 格式（.xlsx, .xls）
   - 字段映射规则在 `dataCleaner.js` 里，可以根据实际情况调整

3. **错误处理**：
   - 如果 Agent 调用失败，前端会显示错误信息
   - 建议在开发环境打开详细错误日志，生产环境隐藏

## 📞 遇到问题？

1. **Agent 调用失败**：
   - 检查 `server/.env` 的 API Key 是否正确
   - 检查 Dify Base URL 是否正确
   - 查看后端日志，看具体错误信息

2. **Excel 清洗失败**：
   - 检查 Excel 文件格式是否正确
   - 检查字段映射规则是否匹配你的 Excel 列名
   - 可以在 `dataCleaner.js` 里调整字段映射

3. **前端显示异常**：
   - 检查浏览器控制台错误
   - 检查网络请求是否成功
   - 检查后端接口是否正常返回
