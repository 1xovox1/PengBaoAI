========================================
  重要提示：如何正确访问应用
========================================

❌ 错误方式：
   - 直接双击打开 index.html 文件
   - 使用 file:// 协议访问

✅ 正确方式：
   1. 确保开发服务器正在运行
      - 运行 npm run dev
      - 或双击 start.bat

   2. 在浏览器中访问：
      http://localhost:3000

   3. 不要直接打开HTML文件！

========================================
  如果页面是空白的，请检查：
========================================

1. 开发服务器是否正在运行？
   - 查看命令行窗口，应该显示 "VITE v5.x.x ready"
   - 应该显示 "Local: http://localhost:3000/"

2. 是否通过 http://localhost:3000 访问？
   - 地址栏应该显示 http://localhost:3000
   - 不是 file:/// 开头

3. 浏览器控制台（F12）是否有错误？
   - 打开开发者工具（F12）
   - 查看 Console 标签页
   - 查看 Network 标签页

4. 尝试访问测试页面：
   - http://localhost:3000/simple
   - http://localhost:3000/test

========================================
  快速启动步骤：
========================================

1. 双击 start.bat
2. 等待服务器启动（看到 "ready" 提示）
3. 浏览器会自动打开，如果没有，手动访问：
   http://localhost:3000
